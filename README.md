# bin-utils

A collection of personal shell scripts

## Contents

| Script | Description |
|---|---|
| [`pplx`](./pplx) | CLI wrapper for querying the Perplexity API from the shell |
| [`mkbk`](./mkbk) | Creates a timestamped backup copy of a file before editing |

## Usage

Clone the repo and add it to your `PATH` to run scripts from anywhere:

```bash
git clone https://github.com/fdjutant/bin-utils.git
export PATH="$HOME/bin-utils:$PATH"
```

Add the `export` line to `~/.bashrc` to make it permanent.
